# Edu Ride A7670E LTE Carrier

Separate prototype daughterboard for the Edu Ride ESP32-S3 controller. Read `DESIGN.md` before changing the schematic or board. The existing controller board is intentionally not modified.

Current milestone: architecture and component candidates recorded. Exact module land pattern, detailed regulator design, schematic, layout, DRC, power/thermal/RF/USB validation remain open. No manufacturing files are released.
