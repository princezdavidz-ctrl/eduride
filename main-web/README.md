# Edu Ride

Build a modern, professional, production-ready website for Edu Ride, a school transportation safety technology company.

BRAND:

Company name: Edu Ride

Industry: Child Safety / School Transportation / GPS Tracking / IoT

Tagline: "Every Journey. Safely Tracked."

Core idea: Edu Ride provides intelligent school-bus safety using a compact coded PCB/IoT tracking device installed in school buses. The device communicates with a cloud server, tracks the vehicle, records journey information, and sends SMS/notifications to parents, schools, and administrators.

The website is a company and services overview for schools and transport operators. It is not a parent portal and must not offer parents web access to track children or school buses. Family communication is a school-managed service delivered through configured SMS/mobile app notifications.

DESIGN DIRECTION:

Create a premium global technology brand similar in quality to modern SaaS, mobility, and security companies.

Use:

- Clean modern interface with light surfaces

- App brand blue (#1769E0), green logo accents, and school-bus yellow safety signals

- Rounded cards

- Subtle gradients

- Smooth animations

- Large bold typography

- Lots of whitespace

- Professional icons

- Responsive design for desktop, tablet and mobile

The visual identity should communicate:

SAFETY + TRUST + TECHNOLOGY + MOVEMENT + CHILD PROTECTION.

Use the Edu Ride app logo from `public/edu-ride-logo.jpeg` and the app's blue-and-green palette throughout the website. Use "Edu Ride" prominently throughout the website.

02 — TRACK

03 — PROCESS

04 — NOTIFY

Schools can share relevant journey alerts with families through SMS and mobile app notifications. This website does not provide parent web tracking.
